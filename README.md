# شعر و تال غفور

وب‌اپ فارسی/دری برای مدیریت تال‌های صوتی و تصویری، راگ‌ها و شعرها. مناسب انتشار در GitHub Pages.

## انتشار در GitHub Pages
1. تمام فایل‌های این پوشه را در ریشه مخزن GitHub آپلود کن (از جمله `index.html`, `photo.jpg`, آیکن‌ها، `manifest.webmanifest` و `sw.js`).
2. در مخزن به **Settings → Pages** برو.
3. گزینه انتشار از شاخه (Deploy from a branch) و شاخه `main` و پوشه `/(root)` را انتخاب کن.
4. پس از فعال‌شدن، لینک Pages را با Safari باز کن. Service Worker فقط در HTTPS/محیط مناسب ثبت می‌شود.
5. برای نصب روی iPhone، در Safari گزینه Share و سپس Add to Home Screen را بزن.

## قابلیت‌های پیاده‌سازی‌شده
- رابط راست‌چین، تم‌های آمادهٔ روشن/تاریک (آیفون، شیری/قهوه‌ای، چوب، گلدار، موتر، فرش، آب، شیشه، کاغذدیواری و طبیعت) و تنظیم رنگ دلخواه؛ سطوح تخت بدون گرادیانت و سایه.
- افزودن، ویرایش، مرتب‌سازی، علاقه‌مندی و انتقال تال به سطل زباله؛ افزودن چند فایل صوتی/تصویری در هر تال.
- نگهداری Blob رسانه‌ها در IndexedDB به‌جای آدرس موقت؛ پخش HTML5، مکث، توقف، seek، سرعت ۱×/۲× و تکرار خودکار تال.
- راگ‌ها و سه دسته آرام، متوسط و مست؛ افزودن/ویرایش شعر، انتخاب تال مرتبط، اندازه متن، حذف نرم و بازیابی.
- جست‌وجوی تال، نام فایل، راگ، عنوان و متن شعر؛ عادی‌سازی حروف رایج ک/ك و ی/ي.
- مرتب‌سازی شعرها با دکمه‌های بالا/پایین و کشیدن در دستگاه‌های پشتیبانی‌شده؛ واردکردن متن TXT/Markdown، خروجی شعر TXT، خروجی JSON کامل/بدون رسانه، ادغام پشتیبان JSON و آزمایش ساختار پشتیبان.
- تاریخ خورشیدی با تقویم Persian پشتیبانی‌شده در Intl مرورگر و تاریخ میلادی.
- پوسته آفلاین با Service Worker پس از بازدید موفق در HTTPS.

## نکات و محدودیت‌های صادقانه
- رسانه‌های شخصی فقط در فضای محلی مرورگر همان دستگاه هستند. GitHub Pages آن‌ها را به حساب یا دستگاه دیگر همگام نمی‌کند. پشتیبان‌گیری منظم ضروری است.
- انتخاب و ذخیره Blobهای بزرگ به ظرفیت آزاد و سیاست‌های پاک‌سازی مرورگر وابسته است.
- پخش واقعی به کدک و پشتیبانی مرورگر از فرمت وابسته است؛ MP3 معمولاً در Safari پشتیبانی می‌شود، اما این بسته در این محیط به‌صورت خودکار روی دستگاه فیزیکی iPhone آزمایش نشده است.
- Media Session در صورت پشتیبانی مرورگر تنظیم می‌شود. iOS ممکن است هنگام بسته‌شدن کامل Safari یا پایان‌دادن به فرایند، پخش را متوقف کند؛ پخش پس‌زمینه تضمین‌شده نیست.
- عکس انتخابی از تنظیمات فعلاً پیش‌نمایش همان نشست است؛ برای جایگزینی پایدار، عکس را با نام `photo.jpg` در ریشه مخزن جایگزین کن.
- برای جلوگیری از ادعای نادرست، این README مدعی آزمایش روی آیفون واقعی، همه کدک‌ها یا همه آزمون‌های فهرست‌شده نیست.

## فایل‌ها
- `index.html`: رابط، CSS و JavaScript برنامه.
- `photo.jpg`: عکس شخصی ارائه‌شده.
- `icon.png`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`: آیکن‌های برنامه؛ رنگ نارنجی آیکن اصلی به طیف طلایی نزدیک شده است.
- `manifest.webmanifest`: تنظیمات نصب وب‌اپ.
- `sw.js`: کش پوسته برای استفاده آفلاین پس از بارگیری موفق.


## به‌روزرسانی رابط شعر و تال
- در هر راگ و دستهٔ آرام/متوسط/مست، فولدرهای تال برای فیلتر شعرها افزوده شده‌اند.
- بازکردن شعر اکنون صفحهٔ مستقل تمام‌صفحه نشان می‌دهد و بستن آن به موقعیت قبلی فهرست برمی‌گردد.
- هر شعر شناسهٔ فایل تال انتخاب‌شده را نیز نگه می‌دارد تا هنگام بازکردن دوباره همان فایل هایلایت و آمادهٔ پخش باشد.
- رنگ‌بندی دارک و لایت به‌صورت دو پالت مستقل ذخیره می‌شود؛ تغییر تم بلافاصله اعمال می‌شود.


## اصلاحات نسخه 1.1
- واردکردن JSON با نگاشت شناسه‌های تال و راگ به شعرها؛ حفظ اطلاعات موجود، جلوگیری از تکرار در واردکردن دوباره و بازگردانی حالت قبلی در صورت شکست ذخیره.
- فایل TXT دارای نشانگر شعر برای حفظ سطرها و بندهای خالی در خروجی و واردکردن.
- تکرار بومی رسانه با ویژگی loop مرورگر؛ تغییر سرعت از طریق playbackRate بدون تایمر یا توقف مصنوعی.
- کش پوسته به نسخهٔ جدید ارتقا یافت تا فایل تازه پس از انتشار دریافت شود.
